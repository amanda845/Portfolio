## ✨ Fonctionnalités Clés

- 🎨 **Design Haute Couture (Black & Scarlet Red) :** Palette contrastée, typographies élégantes (*Bricolage Grotesque*, *Instrument Serif*, *JetBrains Mono*), glassmorphism et lueurs néon subtiles.
- 📱 **100 % Responsive & Mobile First :** Optimisé pour toutes les résolutions d'écrans (smartphones, tablettes, ordinateurs portables et écrans larges) avec zones tactiles ergonomiques.
- ⚡ **Ultra Rapide & Sans Framework Lourd :** Construit en HTML5, CSS3 pur et JavaScript vanilla pour un score de performance maximal et un chargement instantané.
- 📄 **CV A4 Interactif & Imprimable :** Page dédiée (`cv.html`) au format A4 exact avec bouton d'impression / export PDF direct en un clic.
- 💫 **Micro-interactions & Animations :** Écran de préchargement interactif, boutons magnétiques, parallaxe au curseur et rubans animés (*marquees*).
- 📋 **Formulaire de Contact Moderne :** Validation en temps réel avec retours d'état stylisés.

## 💻 Lancement Local

### 1. Cloner le projet
```bash
git clone https://github.com/amanda845/Portfolio.git
cd Portfolio
```

### 2. Lancer avec NPM
```bash
npm run dev
```
> Ouvrez votre navigateur sur **http://localhost:3000**

### 3. Ou ouvrir directement
Double-cliquez simplement sur `index.html` pour l'ouvrir dans votre navigateur favori.
